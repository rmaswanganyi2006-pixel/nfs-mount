Frequently Asked Questions

SSHFS allows you to mount a remote directory securely over SSH, making it appear as a normal folder on your computer.
The first connection saves the server fingerprint so future connections can verify the server automatically.
Download it from your Computer Science practical resources or the location provided by your lecturer.
SSHFS authenticates using your Stellenbosch University account, so entering your password is expected.
Troubleshooting
  • Connection refused
    Check your internet connection or ensure you are on the university VPN if required.
  • Permission denied
    Verify your student number and password.
  • sshfs: command not found
    Install SSHFS using your operating system's package manager.
  • Host key verification failed
    Remove the old host entry from your ~/.ssh/known_hosts file and reconnect.
